# Helpy Context Map

## Project Summary

Helpy is a macOS SwiftUI focus assistant built as a Swift package. The main UI surfaces are the side strip, floating pill, menu bar panel, reminder rows, and assistant/settings views.

## Current Notes

- The floating pill and its detached subtask panel share a common Liquid Glass container modifier for the glass theme.
- Theme-specific fallbacks still matter because the package supports macOS 14+ with macOS 26-only APIs gated behind availability checks.
